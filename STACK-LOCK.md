# Technology Stack Lock

## Languages
- JavaScript (ES modules) everywhere.
- JSX for React and React Native UI.
- SQL only through migrations/raw queries when Prisma is insufficient.
- No TypeScript.

## Web
- React 19
- Vite
- Tailwind CSS 3
- React Router
- TanStack Query
- React Hook Form
- Zod
- Lucide React

## API
- Node.js 22+
- Express
- Prisma Client
- Neon PostgreSQL
- Zod
- jose for JWT
- bcryptjs for passwords
- pino for structured logging
- helmet, cors, express-rate-limit

## Mobile
- Expo
- React Native
- NativeWind
- Expo Secure Store
- React Navigation
- TanStack Query

## Testing
- Vitest
- Supertest

Do not substitute the core stack without an explicit engineering decision from the project owner.
