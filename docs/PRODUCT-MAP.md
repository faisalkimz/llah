# Product Map

Llah lets a software company create a workspace, issue API keys, define customers and meters, ingest usage, aggregate that usage, attach pricing, manage subscriptions, close billing periods, generate immutable ledger entries and invoices, reconcile payments, apply credits/refunds/adjustments, expose revenue analytics, send alerts/webhooks and operate the platform through audited admin/support tooling.

## Primary personas
- Workspace Owner: controls company, team, billing rules and security.
- Billing/Finance Operator: pricing, invoices, credits, refunds, reconciliation and reports.
- Developer: API keys, meters, event ingestion, logs and webhook debugging.
- Executive: revenue/usage overview on web/mobile.
- Llah Support/Admin: limited audited platform support.

## Core flows
1. Sign up -> verify -> create workspace -> invite team.
2. Create API key -> customer -> meter -> send usage event.
3. Aggregate usage -> configure product/price/plan -> subscribe customer.
4. Close billing period -> ledger -> invoice -> collect/reconcile payment.
5. Apply credit/adjustment/refund when necessary.
6. Monitor revenue, usage, alerts, logs and webhook deliveries.
7. Operate securely with audit history, jobs, observability and backups.
